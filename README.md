# EveriArt — everiart.com

Source for the EveriArt creative house website.

**Live:** https://everiart.com
**Hosting:** Netlify (site: `everiart`)

## Studios

- **ByEveriArt** — film and cinematography
- **EveriDesign** — brand identity
- **BeFrames** — photography

## Stack

Static HTML/CSS/JS. No framework, no build step. Deploys as-is.

```
index.html
css/
  tokens.css   design tokens — palette, type scale, motion constants
  base.css     reset, typography, layout primitives
  site.css     components
js/
  spring.js    spring physics engine (velocity-aware, interruptible)
  main.js      interaction layer
assets/        imagery
```

## Design system

Palette (Refined Minimalist Authority):

| Role | Name | Hex |
| --- | --- | --- |
| Dark anchor | Midnight Navy | `#1C2541` |
| Ink | Deep Charcoal | `#212121` |
| Accent | Gunmetal | `#3A506B` |
| Secondary | Stone Gray | `#8E8E8E` |
| Warm base | Parchment | `#F4F1DE` |
| Cool base | Soft Off-White | `#F8F8F8` |

Typography: Instrument Serif (display), Instrument Sans (body/UI). Tracking is
size-specific — display tightens to `-0.045em`, body sits at `0`, small labels
open to `0.06em`.

## Motion

Animation uses a custom spring engine (`js/spring.js`) rather than CSS
transitions, so interactions are interruptible and velocity-aware:

- Springs animate from the **current on-screen value**, never the target — an
  interrupted animation continues from where it is instead of jumping.
- Re-targeting carries existing velocity through, avoiding a reversal "brick wall".
- Parameters are damping ratio + response, not mass/stiffness/damping.
  Default UI is critically damped (`damping 1.0`, `response 0.36`); bounce is
  reserved for momentum-driven gestures only.
- 2D motion decomposes into independent X and Y springs.

`prefers-reduced-motion`, `prefers-reduced-transparency` and `prefers-contrast`
are all respected.

## Swapping in real work

Replace files in `assets/` at the same filenames — no code changes needed.

| Slot | Files |
| --- | --- |
| Hero | `hero.jpg` |
| Studio visuals | `studio-film.jpg`, `studio-photo.jpg` |
| Film work | `work-film-01.jpg` … `work-film-05.jpg` |
| Identity work | `work-identity-01.jpg` … `work-identity-05.jpg` |
| Photography work | `work-photo-01.jpg` … `work-photo-05.jpg` |

Card titles, years and disciplines are edited directly in `index.html`.

Placeholders were generated by `make_placeholders.py` (dev utility, not part of
the site).

## Local preview

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000. A server is required — `js/main.js` is an ES
module and will not load over `file://`.

## Secrets

None are committed. Anything sensitive belongs in Netlify environment variables,
